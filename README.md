# 🤖 Automatización Web con Playwright

Portafolio de QA Automation - Pruebas automatizadas con Playwright + JavaScript.

## 🚀 ¿Qué hace este proyecto?

Automatiza pruebas de una página web para verificar que el Login funcione bien.

### Pruebas incluidas:

**1. Login Exitoso**
- Entra con usuario y contraseña correctos
- Verifica que sí entre al sistema

**2. Login Fallido**
- Entra con contraseña incorrecta
- Verifica que muestre mensaje de error y NO deje entrar

**3. Búsqueda en Bing**
- Busca automáticamente en Bing y verifica resultados
